# شركة درر الوطنية لتأجير السيارات — نسخة عرض (Vue 3 + Vite)

موقع عرض تجريبي ثنائي اللغة (عربي/إنجليزي) لفرع السليمانية في الرياض.

## التشغيل
```bash
npm install
npm run dev      # تطوير
npm run build    # بناء إلى dist/
```
النشر على Vercel: Build `npm run build` — Output `dist`.

## الهوية
- ألوان اللافتة الحقيقية: أصفر `#ffc72c` + أحمر `#e63b2e` + أزرق `#2a35b8`، بحدود سوداء وظلال مُزاحة (طابع لافتات الشارع).
- خطوط: Lalezar / Tajawal للعربي، Archivo Black / Archivo للإنجليزي.
